## 2025-02-12 - Robuster CLI UX Layout and Color Alignment
**Learning:** For command-line developer interfaces that execute in varying terminal/shell configurations (including legacy Windows CP1252 consoles and non-TTY CI environments), using standard ASCII characters (`-`, `=`, `|`) instead of Unicode box-drawing characters is essential to prevent `UnicodeEncodeError`. Additionally, when formatting tables with ANSI-colorized cells, standard padding functions (e.g., Python's `f"{val:<10}"`) will count the escape codes towards string length and break column alignment. Row status values must be padded on their raw uncolored length before adding escape codes, or the trailing space padding must dynamically subtract the uncolored text length.
**Action:** Next time, always use standard ASCII characters for structural CLI elements and calculate padding length based on raw uncolored strings rather than colored ones.
