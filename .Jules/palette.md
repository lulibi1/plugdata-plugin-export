## 2026-05-15 - [Colorized CLI Output and Directory Validation]
**Learning:** For terminal-based tools, color-coded output greatly enhances developer interaction (DX) by immediately drawing attention to errors and status transitions. Furthermore, flexible configuration validation (allowing both files and folders) ensures that users aren't blocked by overly rigid checks on path fields.
**Action:** Always include a lightweight, system-compliant terminal colorization helper (`clr`) in Python build tools, and guarantee inclusive file/directory checks during parameter validation.
