## 2025-01-24 - CLI Output Formatting & Windows Unicode Console Compatibility
**Learning:** Formatting CLI summary tables with ANSI colors can easily break column alignments because ANSI codes take up string length without occupying visual terminal width. Standard padding functions (e.g., f-string width formatting) will align incorrectly. Additionally, using Unicode box-drawing characters (e.g., \u2550) on Windows machines utilizing the `cp1252` encoding throws a `UnicodeEncodeError`.
**Action:** When printing colored status columns, apply color using ANSI escapes but manually calculate padding spaces based on the uncolored status length (e.g., `10 - len(status)`). Ensure all terminal UI lines use standard ASCII character alternatives (e.g., hyphens and equals signs) instead of Unicode box-drawing characters for robust cross-platform console compatibility. Use standard checks for environment variables `NO_COLOR` and `FORCE_COLOR` to adapt gracefully.
