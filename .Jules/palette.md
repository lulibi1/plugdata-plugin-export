# Palette's Journal

## 2025-05-14 - Visual Hierarchy in CLI Tools
**Learning:** Developers often scan verbose build logs for key information. Semantic ANSI coloring (Red for errors, Cyan for progress, Green for success) creates a clear visual hierarchy that reduces cognitive load during debugging and monitoring.
**Action:** Always implement color-coded status messages and a final summary report in CLI-based build systems to improve "at-a-glance" readability.
