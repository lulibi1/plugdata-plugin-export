## 2025-05-14 - Visual Hierarchy in CLI output
**Learning:** Terminal-based tools often suffer from "wall of text" syndrome. Using semantic coloring (Red for Errors, Blue for Progress, Green for Success) and progress counters [i/N] significantly reduces cognitive load and improves the developer experience.
**Action:** Always include a summary report and color-coded status indicators in CLI tools to provide immediate feedback on success/failure states.
