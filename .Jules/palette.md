## 2025-05-14 - [Color-coded CLI Feedback]
**Learning:** ANSI color codes significantly improve the scannability of build logs, allowing users to quickly distinguish between progress, success, and errors.
**Action:** Use a standardized color helper function in CLI scripts to ensure consistent and environment-aware color rendering.

## 2025-05-14 - [Inclusive Validation]
**Learning:** Validation logic should match the flexibility of documented features; restricting paths to only files when the system supports directories creates unnecessary friction.
**Action:** Always verify that validation rules cover all supported input formats (files, directories, etc.) mentioned in the documentation.
