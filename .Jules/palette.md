# Palette's Journal - PlugData Automated Build

## 2025-05-14 - Semantic CLI Feedback
**Learning:** CLI tools used in CI or by developers often output large amounts of text. Using semantic ANSI colors (Red for errors, Green for success, Blue for progress) significantly reduces cognitive load by allowing users to scan for status visually. A final summary ensures that even if the output was verbose, the ultimate result is clear.
**Action:** Always implement color-coded status and a final summary in CLI-based build tools.
